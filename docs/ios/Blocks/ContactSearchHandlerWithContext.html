Block Definition

ContactSearchHandlerWithContext

Callback used by CallKit to asynchronously find a display name for an incoming call using its phone number and additional SIP-to-SIP call data.

typedef void (^ContactSearchHandlerWithContext) (NSString *_Nonnull, callingNumber , NSString *_Nullable, extraContext , void (, ^ _Nonnull, callback )

Discussion

The handler receives the incoming caller’s phone number, optional additional data for the current SIP-to-SIP call supplied by the calling party, and a callback. Invoke the callback with the resolved contact name when the lookup is complete.

Assign this handler to CallKitConfiguration.contactSearchHandlerWithContext. Use ContactSearchHandler when no additional call data is required.
